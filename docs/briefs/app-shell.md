# Brief: app-shell (wiring, saves, build, and the Worker)

**Your files:** `src/main.ts`, anything under `src/app/`, `index.html`, `tools/build.mjs`, `src/server/worker.ts`, `wrangler.jsonc`, `README.md`, `.dev.vars.example`.
**Read:** `src/sim/index.ts` (Sim, NewGameOptions), `types.ts`, `src/render/api.ts` and `index.ts`, `src/ui/api.ts` (AppAPI, Settings, DynastyEntry, UIDeps) and `index.ts`, `src/word/api.ts` and `index.ts`, `src/audio/api.ts` and `index.ts`, `src/ui/css/base.ts` (the page skeleton it expects: `#app`, `canvas#c`, `#ui`), `src/dev/fixture.ts`, `tools/shot.mjs` (its `--html index.html` option bundles an entry into your real page). Other agents are replacing the placeholder `createRenderer`, `createUI`, `createWord` (these three currently throw) and `createAudio` while you work: write against the api.ts contracts, and make `main.ts` degrade loudly but gracefully if one is still a placeholder (so you can test with what exists).

**`index.html`**: the real page: title "LandLord", viewport with `viewport-fit=cover`, theme colour, the three Google Fonts (UnifrakturMaguntia, IM Fell English, IM Fell English SC) with `display=swap`, an inline SVG favicon (a small crowned key or hovel, drawn by you), `#app` > `canvas#c` + `#ui`, a tasteful boot veil ("Lighting the candles…") removed on first frame, a `<noscript>` line, and `<script src="game.js">`. No inline analytics, nothing external but the fonts.

**`src/main.ts`**: boots everything and owns the frame loop: create audio, word, renderer, UI; show the **title** over a living diorama (a real `Sim.create` with a fixed seed fast-forwarded a few months and left running at 1x, with `renderer.setMode('title')`); `AppAPI` implementation; the loop (`sim.step(dt)` with dt clamped to 0.1 s, `renderer.handleEvents` / `sync` / `frame`, `ui.handleEvents` / `update`, `audio.handleEvents` / `update`); pause when the tab is hidden; resize handling; `renderer.canPlace` wired to the sim's `canPlace`; unlock audio on first gesture; error overlay in the game's voice with the technical detail folded away.
**Saves** (`src/app/`): autosave to `localStorage` every 30 game days and on tab hide and before returning to title, wrapped in try/catch everywhere; one slot per mode; **Iron Crown**: the save is deleted when the reign ends and the reign is written to the dynasty hall (`DynastyEntry` list, capped at 50) with an heirloom chosen from what the reign was known for ("a ring of forty keys", "a ledger with no red in it"); the next Iron reign starts with `heirloom` set and one small matching boon you apply through actions (for example a little extra starting gold). Settings persisted and applied (quality to the renderer, volumes to audio, `wit`, court key under `localStorage['ll.courtKey']`). On `game_over` and `demotion` events open the `gameover` screen; on `promotion` save. If `window.claude?.hot` exists, register a snapshot and boot through it as described in comments you write (so a hot update of the page keeps the running reign): feature-detect, never assume.
Expose `window.__ll = { sim, renderer, ui }` for debugging and automated play.

**`tools/build.mjs`**: esbuild `src/main.ts` → `dist/game.js` (IIFE, minified, target es2020, sourcemap external), copy `index.html` to `dist/`, print sizes; `--dev` skips minification; exit non-zero on error.

**The Worker** (`src/server/worker.ts`, plain Workers API, no dependencies): serves `dist/` through the `ASSETS` binding and adds:
- `GET /api/court` → `{ ok: true, model: boolean, gated: boolean }` (`model` is true when the `ANTHROPIC_API_KEY` secret exists; `gated` when `COURT_KEY` is set).
- `POST /api/word` with `{ system, messages, maxTokens?, tier?, key? }` → calls the Anthropic Messages API (`https://api.anthropic.com/v1/messages`, headers `x-api-key`, `anthropic-version: 2023-06-01`) with the model from env `WORD_MODEL` (default `claude-haiku-4-5-20251001`) or `WORD_MODEL_DEFAULT_TIER` for `tier: 'default'` (default `claude-sonnet-5-5`), `max_tokens` clamped to 700, the client's system text appended after a short fixed guard paragraph of your own (this endpoint only voices characters and interprets orders for the game LandLord and must answer in the requested JSON), and returns `{ text }`. Defences, because the URL is public: same-origin check on `Origin`/`Sec-Fetch-Site`; body size cap (64 KB); message count and length caps; if `COURT_KEY` is set, require a matching `key` (constant-time compare) else 401; a per-IP rate limit (use the Workers Rate Limiting binding if configured in `wrangler.jsonc`, and fall back to a small in-memory sliding window per isolate); never echo the API key or upstream error bodies; JSON errors `{ error, code }`. Confirm the Messages API request and response shape against the official docs before you finish (https://docs.claude.com) and do not guess model ids beyond the two defaults named here.
**`wrangler.jsonc`**: name `landlord`, `main: src/server/worker.ts`, a recent `compatibility_date`, `assets: { directory: './dist', binding: 'ASSETS', not_found_handling: 'single-page-application', run_worker_first: ['/api/*'] }` (verify the exact key names against current Cloudflare docs), `workers_dev: false`, a rate limit binding, **no route, no account id, no hostname**: it ships disarmed, with a comment block explaining the three things a self-hoster does (deploy with their own route, `wrangler secret put ANTHROPIC_API_KEY`, optionally `COURT_KEY`). `.dev.vars.example` with placeholder names only.
**`README.md`**: what LandLord is (short, in voice), how to run (`npm install`, `npm run build`, `npx wrangler dev`), how to deploy, the layout of the source, and that it plays fully without any key. No hostnames or identifiers.

**Verify.** `node tools/build.mjs` succeeds and prints sizes. `node tools/shot.mjs src/main.ts .tmp/app-shell.png --html index.html` shows whatever exists so far without an uncaught error (placeholders may make it sparse; the boot veil and error path must behave). Unit-test the Worker's request handling with a fake `fetch` and fake env (`npx tsx`), including every refusal path.
